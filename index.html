01 / FEATURES

ManaRingでできること

リングメニューの表示方法や、アイコンの選択方法を設定できます。

01
◎

カーソルの周りに表示

リングメニューをマウスカーソルの周囲に表示。使いたい場所で、そのままアクセスできます。

02
↗

ホットキーなどで呼び出す

ホットキー、時計回り・反時計回りのジェスチャー、画面端ダブルクリックに対応。

03
◌

リングを回して選ぶ

マウスホイールや矢印キーでアイコンを選択。アイコンのクリックでも選択位置まで回転します。

04
▦

複数ページで整理

アプリやフォルダーをページごとに整理。各アイテムには好きな画像をアイコンとして設定できます。

02 / CUSTOMIZE

アイコンを好きな画像に変更

登録したアイテムごとに画像を指定できます。画像を指定しない場合は、起動するファイルのアイコンを使用します。

04 / HOW TO USE

基本的な操作

マウスやキーボードからリングを操作できます。

リングを表示 Ctrl + Alt + Space 初期ホットキー
アイコンを選択 マウスホイール / ← → リングを回転
アイテムを起動 Enter / 左クリック 選択中のアイテムを実行
ページを切り替え ↑ ↓ / Space 右ボタン＋ホイールも対応
リングを閉じる Esc 中央アイコンのクリックでも閉じる

操作方法や設定項目の詳細は、製品付属の取扱説明書をご確認ください。
